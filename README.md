# Cyber Terminal

A Python-based cybersecurity terminal project built for learning networking, Linux, Python, and cybersecurity concepts.

## Features

- Real socket-based port scanning
- Ping targets
- Resolve hostnames to IP addresses
- Log scan activity with timestamps
- System information display
- Network status checks
- Terminal-style command interface

## Commands

Display available commands:

```bash
help
```

Run a real TCP port scan:

```bash
scan google.com 20 100
```

Ping a target:

```bash
ping google.com
```

Resolve a hostname:

```bash
resolve google.com
```

Display saved logs:

```bash
logs
```

Clear the log file:

```bash
clearlogs
```

Display cyber terminal status:

```bash
status
```
